1. 建立自己的 Key Pair

建立一組 RSA-OAEP 2048-bit Public Key / Private Key

Generate Key Pair
🔑 Public Key
可以分享給其他人
🗝️ Private Key
應由自己保存，不應公開
教學提示：Public Key 可以給其他人，用來「加密資料給你」；Private Key 則用來把資料解密。 一組 Public Key 和 Private Key 是互相配對的。
🔒

2. 加密文字

貼上收件者的 Public Key，再輸入要加密的文字

Encrypt
要把資料安全傳送給某人，請使用收件者的 Public Key進行加密。
Plaintext→Public Key→Encrypted Text
Encrypted Text
把整段文字複製給收件者
🔓

3. 解密文字

貼上自己的 Private Key 和 Encrypted Text

Decrypt
解密必須使用與加密時 Public Key 相配對的 Private Key。 使用其他人的 Private Key 將無法成功解密。
Encrypted Text→Private Key→Plaintext
Decrypted Text
成功解密後會還原原本文字
